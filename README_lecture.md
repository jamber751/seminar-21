# Голосовой бот регистратуры

Учебный проект лекции 21 «Голосовые и realtime-системы». Бот отвечает по телефону регистратуры учебной поликлиники номер 7: находит пациента по ИИН, называет свободное время врача и записывает на приём. Все пациенты, врачи и номера ИИН вымышлены.

## Что нужно

- Python 3.12 и пакетный менеджер uv.
- Ключ Groq (бесплатный, console.groq.com, начинается с `gsk_`) в файле `.env`.
- Для `bot_live.py` ещё ключ Google AI Studio (бесплатный, aistudio.google.com).
- Браузер Chrome и микрофон. Наушники не обязательны: браузер сам гасит эхо динамиков.

Файл `.env` создаётся по образцу `.env.example` и в git не попадает.

## Запуск

```
uv sync
uv run bot.py
```

После строки `Bot ready!` страница http://localhost:7860/client открывает звонок: кнопка Connect, разрешение на микрофон, разговор. Первый запуск скачивает голос Piper (63 МБ) и длится дольше.

На Windows с русской системной кодировкой (cp1251) бот может упасть сразу при старте с `UnicodeEncodeError: 'charmap' codec can't encode characters`. Так бывает, когда вывод идёт в файл или другую программу, мимо окна консоли: рамка заставки Pipecat нарисована символами, которых в cp1251 нет. Переменная окружения `PYTHONUTF8=1` переводит Python на UTF-8; в PowerShell это `$env:PYTHONUTF8 = "1"` перед `uv run bot.py`.

| Команда | Что делает |
| --- | --- |
| `uv run bot.py` | каскад: Silero VAD, распознавание Groq Whisper, модель `openai/gpt-oss-20b`, голос Piper |
| `uv run bot_live.py` | тот же звонок на Gemini Live, речь в речь, те же инструменты |
| `uv run report.py` | разбор последнего звонка: что услышано, что сказано, первый звук и ответ целиком |
| `uv run report.py --detail` | ещё и раскладка паузы перед ответом по частям |
| `uv run record.py` | запись своего банка фраз в `bank/` |
| `uv run replay.py` | фразы из `bank/` идут в работающий бот без микрофона, сценарии из `scenarios/` |

## Файлы

- `bot.py`: голосовая петля, инструменты и проверки.
- `clinic.py`: учебная регистратура: пациенты, врачи, свободное время, запись, проверка ИИН.
- `confirm.py`: согласие абонента на прочитанную запись: ясное по словам, остальное размечает узкий классификатор.
- `journal.py`: журнал звонка, одна строка JSON на событие, файлы `runs/call_*.jsonl`.
- `report.py`: отчёт по журналу.
- `bot_live.py`: вариант на Gemini Live.
- `record.py`, `replay.py`, `bank/phrases.json`, `scenarios/`: проверка голосом без микрофона.

## Шаги лекции

Каждый шаг лекции отмечен тегом git: `git checkout step-03` возвращает проект к состоянию после третьего шага.

| Тег | Что добавляет |
| --- | --- |
| `step-01` | голосовая петля без инструментов |
| `step-02` | журнал звонка и отчёт |
| `step-03` | инструменты регистратуры и фраза «Минутку, смотрю расписание» |
| `step-04` | ИИН: только цифры, ровно 12, контрольная цифра, прочтение по одной цифре; пока пациент не найден, бот ждёт секунду тишины |
| `step-05` | запись только после согласия абонента: ясные ответы решают слова, остальные размечает классификатор (`confirm.py`); без двойной записи; оператор при жалобах и после трёх ответов без согласия |
| `step-06` | после двух неудач с ИИН предложение ввести его текстом и SMS, после трёх оператор; молчание: два переспроса через 8 с, потом прощание |
| `step-07` | `bot_live.py` на Gemini Live |
| `step-08` | `record.py`, `replay.py` и сценарии; постоянное приветствие: бот говорит, что он автоматический помощник и разговор записывается |

## Ограничения

- Бесплатный уровень Groq даёт модели `openai/gpt-oss-20b` 8 000 токенов в минуту и 200 000 токенов в сутки. Двухминутный звонок 18 ноября 2026 года взял 6 803 токена за самую плотную минуту, поэтому два звонка подряд без паузы могут упереться в минутный лимит. Звонок с инструментами стоит около 5 000 токенов, так что суточного лимита хватает примерно на 40 звонков.
- Бесплатный уровень Gemini использует присланные данные для улучшения продуктов Google. Для учебных фраз с вымышленными данными это допустимо, для настоящих звонков нет.
